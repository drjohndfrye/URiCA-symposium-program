Continual Learning for Personalized Voice Command Recognition

Poster Location 12

Ben Burie, Computer Science major

Mentor: Fnu Hairi, Computer Science

Abstract: We aim to expand upon a voice command prototype that leverages a deep learning architecture and allows users to continually perform computer actions through natural speech (e.g. “Create new Word Document”). The goal of this research is to expand upon and optimize the voice command recognition of newly defined commands in terms of latency and accuracy. The current approach explores various continual learning strategies that allow users to seamlessly introduce new commands without requiring full model retraining. These strategies involve experimenting with the class-incremental learning framework iCaRL paired with bias correction. Ultimately, we can visualize a future where improvements to this voice command recognition system could allow for dynamic learning of new commands defined by the user. This would enable personalized task execution by allowing the system to continuously adapt to individual user needs with minimal effect on performance.
